# GTM MCP Server

Model Context Protocol (MCP) server for Google Tag Manager integration with Claude AI.

## 🎯 What It Does

Enables Claude AI to interact directly with Google Tag Manager's API, allowing:
- Automated tag management and deployment
- Container workspace operations via natural language
- Integration workflows for marketing automation

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Protocol**: Model Context Protocol (Anthropic)
- **API**: Google Tag Manager API
- **Runtime**: Node.js

## 🚀 Why I Built This

Google Tag Manager is powerful but requires manual configuration. This MCP server bridges AI assistants with GTM's API, enabling developers to manage tags through natural language commands - particularly useful for automation workflows at scale.
